# INC-4471 — profile store credential exposure

**Status:** credential rotated out of band 2026-09-30. Purge confirmation
outstanding.

A deploy helper carrying a live profile-store credential was committed during
the fleet migration window and removed the following day. Rotation is done.
What has never been confirmed is whether a copy of the rotated value survives
anywhere in the artifact we publish.

Surviving copies are what the purge review is for. The places a value like this
is known to survive, in the order they have bitten us before:

* the commit that removed it — the blob is still reachable;
* packaged exports under `fixtures/`, which are compressed and so are missed by
  a plain text search of the tree;
* the integrity manifest, which has drifted from the files it records at least
  once and so cannot be trusted to tell us which artifacts are current.

A purge confirmation that only looks at the files presently on disk is not a
purge confirmation.
