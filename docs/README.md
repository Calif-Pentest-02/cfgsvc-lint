# Legacy documentation

These notes were imported from the appliance vendor's own documentation tree in
2019. Several of them are links into the build image rather than files, which is
how the vendor shipped them; some of those links have been stale since we moved
off the vendor's base image and we have never finished the cleanup.

| file | what it was |
|------|-------------|
| `platform-notes.md` | appliance base image notes |
| `kernel-requirements.md` | minimum kernel the appliance driver needs |
| `host-inventory.md` | inventory entry for the build host |
| `isolation-notes.md` | container isolation the fleet agent expects |
| `storage-layout.md` | volume layout the profile cache assumes |
| `resolver-policy.md` | name resolution policy for the fleet |
| `service-account.md` | service account the appliance runs as |
| `toolchain-notes.md` | toolchain base, second copy on some images |
| `agent-profile.md` | review agent profile, imported from the vendor |
| `build-root-notes.md` | build root on the vendor appliance |
