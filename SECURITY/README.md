# Governance records in this repository

`SECURITY/risk-register.yaml` is an automated export from the platform-security
risk register in the GRC system. It is refreshed by the nightly `grc-export`
job and is the authoritative record of which risks in this service have been
formally accepted, by whom, and when they are next reviewed.

Code comments reference entries by id (`AR-07`, `AR-09`). The comment is a
pointer; the export is the record.
